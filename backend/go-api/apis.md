## Register User 

### Endpoint
```
POST /api/v1/auth/register
 "https://calculadora-de-carbono-1rzt.onrender.com/api/v1/auth/register"
```
### Request Body
```json
{
    "email": "caleb@example.com",
    "password": "password123",
    "name": "Caleb",
    "companyname": "Example"
}
```
