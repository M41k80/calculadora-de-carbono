🌍 Proyecto: Calculadora de Huella de Carbono para Empresas

🎯 Objetivo
Ayudar a empresas a medir, visualizar y reducir su huella de carbono mediante una plataforma web que integre:

Cálculo automatizado de emisiones (basado en consumo de energía, transporte, etc.)
Predicciones de emisiones futuras
Recomendaciones personalizadas con IA
